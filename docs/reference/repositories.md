`LineageOS/android_hardware_nothing` is **not** the right repo despite the
matching name — it is the Phone (1)/(2) generation, with no `config.mk` and none
of the required HALs.

`NullDebris/manifest` lists every dependency of the tree these forks derive from
and is worth watching for changes.

## Scope

These trees build Frogger and nothing else. Where another device's code is in the
way, delete it rather than widening a condition to admit both; the merge
conflicts on rebase are the accepted price.

## Signing keys

Nine RSA-2048 keys live in `vendor/lineage-priv/keys/` — `releasekey`,
`platform`, `shared`, `media`, `networkstack`, `nfc`, `sdk_sandbox`, `bluetooth`,
`testkey`.

`testkey` is required even though nothing is signed with it:
`system/sepolicy/private/keys.conf` has a `[@RELEASE]` stanza requiring
`$DEFAULT_SYSTEM_DEV_CERTIFICATE/testkey.x509.pem`, without which
`//system/sepolicy/mac_permissions` fails the build. It is deliberately a
different key from `releasekey`.

**The location is load-bearing.** `build/make/core/config.mk` derives
`BUILD_KEYS` from where `DEFAULT_SYSTEM_DEV_CERTIFICATE` points:

```
build/make/target/product/security/testkey  -> test-keys
vendor/lineage-priv/%                       -> release-keys
anything else                               -> dev-keys
```

Keys in the commonly-suggested `~/.android-certs` build as **dev-keys**.
`vendor/lineage/config/common.mk` wires them in with
`-include vendor/lineage-priv/keys/keys.mk`, so no device-tree change is needed.

The `.pk8` files have no passphrase, so the repo being private is the only
protection. If it is ever made public, regenerate all nine.

### Bluetooth certificate

`keys.mk` must set `PRODUCT_MAINLINE_BLUETOOTH_SEPOLICY_DEV_CERTIFICATES`.
`build/make/core/config.mk` does not fall back to the local key directory the way
its NetworkStack sibling does:

```make
ifdef PRODUCT_MAINLINE_BLUETOOTH_SEPOLICY_DEV_CERTIFICATES
  ... := $(PRODUCT_MAINLINE_BLUETOOTH_SEPOLICY_DEV_CERTIFICATES)
else ifneq (,$(filter com.google.android.bt,$(PRODUCT_PACKAGES)))
  ... := $(MAINLINE_SEPOLICY_DEV_CERTIFICATES)
else
  ... := $(dir build/make/target/product/security/testkey)
endif
```

This tree builds `com.android.bt` from source rather than shipping Google's
`com.google.android.bt`, so without the override the third branch wins,
`seinfo="bluetooth"` never matches, and `com.android.bluetooth` stays in the
`zygote` domain.
